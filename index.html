Política de Privacidade

Segurança São Jorge Privada Ltda — Última atualização: Novembro de 2026

RESUMO

O aplicativo Segurança São Jorge coleta apenas os dados necessários para o funcionamento do sistema de segurança privada. Seus dados nunca são vendidos ou compartilhados com terceiros.

1. Informações que coletamos

  • Localização GPS — para monitoramento dos guardas em serviço e resposta a alertas de emergência
  • Nome e e-mail — para autenticação e identificação no sistema
  • Fotos — registradas durante ocorrências de segurança
  • Mensagens de chat — comunicação entre guardas, clientes e administradores
  • Registros de ponto — horários de entrada, saída e pausa dos guardas

2. Como usamos suas informações

  • Monitoramento em tempo real dos guardas de segurança em serviço
  • Resposta rápida a alertas de emergência (SOS) dos clientes
  • Registro e gestão de ordens de serviço
  • Comunicação interna entre equipe e clientes
  • Geração de relatórios operacionais

3. Compartilhamento de dados

Não compartilhamos seus dados com terceiros para fins comerciais. Os dados são armazenados de forma segura no Firebase (Google Cloud) e acessíveis apenas a usuários autorizados do sistema.

4. Segurança dos dados

  • Autenticação segura via Firebase Authentication
  • Banco de dados protegido com regras de segurança rigorosas
  • Acesso restrito por função (admin, segurança, cliente)
  • Comunicação criptografada (HTTPS/TLS)

5. Permissões do aplicativo

  • 📍 Localização — necessária para monitoramento dos guardas e resposta a emergências
  • 📷 Câmera — para registro fotográfico de ocorrências de segurança
  • 🔔 Notificações — para alertas de SOS, ponto e mensagens urgentes
  • 🌐 Internet — para sincronização em tempo real com o servidor

6. Retenção de dados

Os dados são mantidos enquanto a conta estiver ativa. Registros de ocorrências, pontos e ordens de serviço são mantidos por 1 ano para fins de auditoria e conformidade.

7. Seus direitos

  • Solicitar acesso aos seus dados pessoais
  • Solicitar correção de dados incorretos
  • Solicitar exclusão da sua conta e dados
  • Revogar permissões de localização nas configurações do celular

8. Crianças

Este aplicativo é destinado exclusivamente a adultos (+18 anos) para uso profissional em segurança privada. Não coletamos dados de menores de 18 anos.
